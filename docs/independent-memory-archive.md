# 伯恩独立旧日档案库

这套档案与现有 `MemoryItem` 记忆库分仓：

- 旧日档案保存可核对的历史原文与来源；
- 结构化记忆保存现在仍然成立的事实、约定和状态；
- 主聊天只按当前用户话题检索已启用会话，最多注入少量有界证据；
- 当前用户消息、当前人设和最近对话始终优先。

## 从 ChatGPT 导出生成档案包

原始导出目录中应包含 `conversations-000.json` 等文件。在桌面端仓库目录运行：

```bash
npm run archive:build -- "/path/to/chatgpt-export" "/safe/path/burne-history.burne-archive.ndjson"
```

转换器只沿每个会话的当前分支读取用户/助手可见正文，排除隐藏思考、reasoning recap、工具内部消息与被替换分支。原导出不会被改写。

生成的 `*.burne-archive.ndjson` 已被 `.gitignore` 排除，不能提交到代码仓库。

## 在页面中使用

1. 打开「记忆库 → 旧日原文」。
2. 选择生成的 `.burne-archive.ndjson` 文件；页面会流式写入独立 IndexedDB。
3. 核对默认启用的伯恩会话；有误时点一下会话即可关闭或开启召回。
4. 用「原话检索与证据」测试关键词、日期、标题与原文是否正确。
5. 保持「允许主聊天召回」开启。之后主聊天会按话题自动取少量原文证据。

## 数据安全

- 导入失败会回滚本轮残片，不覆盖已存在的同源档案。
- 档案原文只在当前站点的 IndexedDB 中，不进入 localStorage、Supabase 或 Git 仓库。
- 当前「整包备份」不包含这座独立档案库；请保留原始 ChatGPT 导出和生成的档案包，以便换设备后重新导入。
