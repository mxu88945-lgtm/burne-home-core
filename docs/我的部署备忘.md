## 💬 朋友的中转站（Sub 渠道）怎么配

在小手机「设置 → API / 模型」里：

1. **base URL**：`https://sub2api.ztsyy.com/v1`
2. **API key**：朋友给的那个（只存在手机本地）
3. **模型名**：手动填（目前用 `gpt-5.5`；换模型问朋友支持哪些）
4. ✅ **勾上「经 Worker 中转」**（这个站不支持浏览器直连，必须走 Worker）
5. 点圆圈**选中它**（变成实心 ●）才是在用它

> ⚠️ 「获取模型」按钮对这个站会报 `Load failed`（正常现象，因为拉列表是浏览器直连被拦），**手动填模型名就行**。

## 🔁 以后要「更新 Worker 代码」怎么办（很少用到）

只有改了 `worker/` 里的代码才需要。步骤：

1. 电脑装好 Node.js（一次就够）。
2. 下载最新代码 ZIP：
   ```
   https://github.com/mxu88945-lgtm/burne-home-core/archive/refs/heads/claude/new-frontend-repo-x02o8y.zip
   ```
   解压 → 进 `worker` 文件夹 → 地址栏打 `cmd` 回车开终端。
3. 终端里：
   ```
   npm install
   ```
4. **生成一个临时 API 令牌**（部署用，用完删）：
   - 浏览器开 https://dash.cloudflare.com/profile/api-tokens
   - 创建令牌 → 用模板「编辑 Cloudflare Workers」→ 啥都不改 → 创建 → 复制
5. 终端里（`=` 后右键粘贴令牌）：
   ```
   set CLOUDFLARE_API_TOKEN=粘贴令牌
   npx wrangler deploy
   ```
6. 看到 `https://burne-home-core.mxu88945.workers.dev` 就是部署成功 ✅
7. **部署完去把那个令牌删掉**（API 令牌页 → 删除），安全。

> 小贴士：终端里**右键 = 粘贴**；别按 `Ctrl+C` 或 `Y`，让它自己跑完。

## 🧠 重要概念（怕忘）

- **Worker = 我自己的中转服务器**：手机 → 我的 Worker → 朋友的中转站 → 回复。全程不需要我的电脑。
- **为什么需要 Worker**：网页有「跨域(CORS)」限制，有些中转站不让浏览器直连；Worker 在服务器端帮忙转，就绕过了。
- **key 都只存手机本地**，不上传、不进代码仓库。
